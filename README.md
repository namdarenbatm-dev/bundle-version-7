# Techno Bundle — ورژن ۷

PWA فارسی و راست‌چین برای طراحی باندلینگ توسن تکنو.

- صفحه آغازین ۵ ثانیه‌ای با لوگوی PNG و پس‌زمینه دقیقاً سفید (#FFFFFF) برای جلوگیری از اختلاف رنگ
- فونت یکان همراه پروژه
- نمای مدیریت، نمای کارگزار و صفحه فرمول‌های فارسی
- منطق مالی اصلی در `engine.js` حفظ شده است
- پیشنهاد هوشمند: اولویت بیشترین تعداد کارتخوان و سپس کمترین قیمت هر کارتخوان؛ پیشنهاد ارتقا فقط در صورت بهتر بودن و تا سقف ۱۰۰ میلیون تومان بالاتر از بودجه

برای اجرا، فایل‌ها را در مخزن GitHub قرار دهید و GitHub Pages را فعال کنید. برنامه را از طریق یک سرور HTTP/HTTPS باز کنید، نه `file://`.

قبل از استفاده عملیاتی، `npm test` را اجرا کنید و خروجی سناریوهای مالی را با مقادیر مصوب بررسی کنید.
